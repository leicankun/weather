# 天气出行 Agent 联合评测

评测当前单、多智能体的任务质量、工具调用、耗时与供应商用量。入口为 `backend/app/scripts/agent_benchmark.py`，题集和合成工具数据位于 `agent_benchmark_data.py`，统计复算入口为 `report_agent_benchmark.py`。

## 固定设计

- 固定2026-10-25为日期锚点，共40题：天气8、穿搭6、路线6、资料与时效信息6、复合任务8、追问/更正/切换6。所有场馆及返回信息都是合成测试数据。
- 每题每模式3次，总计240次；固定种子20261025打乱两种模式与重复次序，最多4个图请求同时执行。先完成全部推理，再统一评分，评分请求不会穿插进推理耗时。
- 使用实际项目配置的对话模型、真实Embedding和当前LangGraph，包括语义路由、原有工具预算、日期校验、汇总及内置核验。保留真实MCP及本地工具的名称、描述和参数schema，只在独立评测进程替换工具执行，固定每次20毫秒等待。
- 这是一轮受控的Agent系统评测，不是实际天气/地图正确性、端到端HTTP/SSE、数据库、自动记忆写入或Checkpointer恢复评测。匿名直接执行图，不读写数据库；不改.env或生产服务代码。

## 评分规则

任务质量原计划按预先写入题集的必要要点评分，同时核对回答行为、无依据事实及事实冲突。评分调用同一个配置模型，温度0，输入不带单/多模式标识；保存原始评分JSON和逐项理由。图异常和空回答为任务失败。评分服务错误为未知，不等于Agent答错；评分不全时不计算完整语义质量总体通过率。401/402/403会触发评分熔断，不对后续样本反复发送已知无效请求。

工具评分检查实际执行的工具及日期、城市、指定路线起终点、怕冷偏好等明确约束；可接受等价调用路径。例如穿搭和路线结果已含对应天气，不额外强制要求独立天气调用。模型提出的调用、真正进入工具执行的调用、预算或日期守卫拒绝的调用分别保留。参数检查仅覆盖题集中声明的约束，不等同所有参数的完整语义验证。

耗时覆盖初始状态构造、路由、工具循环、汇总和系统内置核验，排除预热和独立自动评分。记录均值、P50/P95、输入/输出聊天Token、路由Embedding Token、模型调用及HTTP重试。缺失usage计为未知，不推断成免费；聊天、Embedding和评审消耗分开，不估算未经核实的人民币金额。

模型HTTP客户端可能是httpx或httpx2，脚本分别监测Embedding与实际LangChain客户端。原始模型回调与供应商HTTP usage同时保存；若有模型调用而捕获不到聊天HTTP，脚本会拒绝生成误导性的零用量报告。

## 运行与复算

在backend目录执行，需要已有项目虚拟环境、MCP依赖及真实对话/Embedding配置，会产生外部API调用费用：

```powershell
.\.venv\Scripts\python.exe -m app.scripts.agent_benchmark --output <新的绝对目录> --repeats 3 --workers 4
.\.venv\Scripts\python.exe -m app.scripts.report_agent_benchmark <结果目录>
```

已有目录默认拒绝覆盖。`--resume`只允许相同代码哈希、题集哈希与重复次数，复用已保存推理及评分；不得用续跑掩盖更改题集或评分规则。预跑使用独立目录和`--pilot --limit 2 --repeats 1`，不混入正式结果。

输出包括metadata.json、dataset.json、tool_schemas.json、inference.jsonl、runs.jsonl、warmup.json、code_snapshot/、REPORT.md、failures.md、trial_metrics.csv、summary.json和audit.json。源文件快照排除.env，报告保存当前未提交服务代码的实际内容与哈希，不会假定HEAD就是实际执行版本。

自动评分不是独立人工评价。多智能体始终核验专业回答，单智能体只在原有日期条件下核验，两者工具预算与提示词也不同，所以结果只能用于当前完整系统比较，不能归因于某一个组件。三次重复用于观察波动，不把它们当成三倍独立题量，也不承诺线上总体准确率或生产吞吐量。

## 验证

2026-10-25推理240/240完成，无图异常。单/多模式必要工具能力144/147、147/147；平均图执行7.63/8.38秒，平均聊天Token7752.3/6092.5。自动语义评分33/240成功后接口余额不足（HTTP 402），207份未完成，不报告完整语义准确率；后续新增了评分熔断并用模拟402验证，没有再调用付费接口测试熔断。

离线脚本`score_agent_benchmark_offline.py`对全部240份回答进行关键要点检查，单114/120、多117/120全部满足；要点覆盖236/252、249/252。这是事后公开的离线v2规则，修正默认起点、只问地铁以及无需雨天理由三处原rubric过严边界，不是原v1模型语义评分。不得解释为全部事实均有来源或无幻觉率。

复算离线结果使用`python -m app.scripts.score_agent_benchmark_offline <结果目录>`，再运行报告脚本。原始回答、33份模型评分和执行时源代码快照全部保留；当前源码另含运行后增加的熔断和离线分析，不伪称已用于原始推理。实际结果与助手定向复核说明位于本次聊天输出weather-agent-eval-20261025/REPORT.md及REVIEW_NOTES.md。

